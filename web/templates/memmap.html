    MEMORY REGIONS REFERENCE

    The CPU column shows read mappings. ROM writes usually reach the RAM underneath; I/O accesses reach devices. Cartridge hardware can change write behavior. The following describes the normal configuration without a cartridge.

    Zero Page & Stack

    $0000-$00FF: Zero Page - Fast access area for BASIC and KERNAL. The 6510 can address these bytes with shorter, faster instructions.

    $0100-$01FF: Hardware Stack - Used for subroutine return addresses and register saves. Grows downward from $01FF.

    BASIC Program Area

    $0200-$9FFF: Main RAM - System workspaces, BASIC programs, variables, and data. Cartridge modes can replace or disconnect parts of this area.

    $0400-$07FF: Default screen block: 1000 screen codes and sprite pointers at $07F8-$07FF. Color RAM is separate, at $D800.

    $0801: Start of BASIC text - where programs are stored.

    ROM Areas

    $A000-$BFFF: BASIC ROM (8KB) - Contains the BASIC V2 interpreter. Requires both LORAM and HIRAM.

    $E000-$FFFF: KERNAL ROM (8KB) - The operating system with I/O routines and interrupt handlers. Controlled by HIRAM bit.

    I/O & Character ROM

    $D000-$DFFF: I/O Area - VIC-II ($D000), SID ($D400), Color RAM ($D800), CIA 1 ($DC00), CIA 2 ($DD00).

    With LORAM or HIRAM high, CHAREN selects I/O (1) or character ROM (0). With both low, RAM is visible. Cartridge modes modify these rules; Ultimax leaves I/O visible and disconnects RAM in its unmapped regions.
